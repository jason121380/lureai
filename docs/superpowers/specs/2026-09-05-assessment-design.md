# 全面評估修正設計

使用者已在閱讀完整評估報告後授權「全部修」。對應 F01–F12。

## 範圍與架構

保留 Python 標準庫、SQLite FTS5、vanilla JS 及無 Volume 的既有部署。以快照寫入資格、單寫入者、歷史版本與終止處理修正 F01/F08；本次不把全部 SQLite 查詢改寫為 PostgreSQL。這個選擇符合報告短期方案，代價是仍不提供多實例水平擴展。

對話同步使用伺服器版本條件、逐筆 ACK、持久墓碑及衝突保留，避免覆寫與復活。模型呼叫建立有狀態的用量生命週期、有限輸出與全域併發控制，正確處理 completed/incomplete/EOF/disconnect。預算以一致性讀取及保守預留控制，未知費用保留而非零成本。

密碼新建／重設提高門檻，既有帳號仍可登入；不因部署設定舊密碼鎖住既有帳號。新增獨立 RAG 評測、引用與數值支持診斷、品質失敗訊號、CI 及操作文件。引用診斷不能假稱語意正確性證明；不用付費模型或正式服務做破壞性測試。

## 驗收

每項修正有先失敗後通過的回歸證據；全套既有測試持續有效（契約變更的測試須更新到新契約，不可刪除以通過）。新增同步衝突、還原失敗、舊寫入者、超额與串流中斷案例。瀏覽器 smoke 及真實 PostgreSQL 測試在可用環境執行；不能執行者有 CI/操作指令與明確限制。

## 不變約定

繁體中文 UI；保留 expert/service/line 與 lurebot API；LINE 不送降級來源文字；沒有可調停頓面板；知識數字與手冊不任意修改；不加入 Volume；不得在註解或 commit/PR 出現模型名稱。不得把真實模型評測、正式部署驗證或 MFA 外部設定標成已完成。
